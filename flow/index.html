Purpose-built functions

General (text→media), Edit, Animate (image→motion), Transition & Stitch between frames, and Act & Speak — a character that moves and lip-syncs.

Nodes that connect

An image node feeds a video node; a character feeds a talking clip. Outputs flow downstream, so a whole campaign lives on one board.

Multi-step composers

Showcase (a product → a full ad set), Storyboard (a scene per beat), and Carousel (consistent slides) build sequences in one pass.

References & keyframes

Video timeline

AI agents

An AI assistant that creates for you.

A full REST API mirrors the app, so an agent authenticates with a key and does the work — generating media, wiring up projects, and authoring complete, editable designs. One call to a self-describing guide teaches it the whole system.

Self-describing API

The agent guide endpoint returns the whole system — endpoints, models, credits — so an agent learns it in one request.

Designs from a brief

The agent writes a compact layout spec — like HTML — that compiles into real, editable vector layers: generated imagery, uploads, brand fonts, multi-colour type.

Render, revise, deliver

It renders a flat proof server-side to QC, revises in place (no duplicates), and hands back a public share link.

Command it anywhere

Because the API is the interface, an agent can take a message — say, over WhatsApp — and return a finished, editable design.
